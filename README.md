# Laboratorio de Organización y Arquitectura de Computadoras

Repositorio del laboratorio de la materia **Organización y Arquitectura de Computadoras** (Semestre 2020-1).

Este repositorio contiene el desarrollo de las prácticas realizadas durante el curso. Con base en la estructura del proyecto, los diseños lógicos se validan y simulan utilizando **ModelSim** (con soporte para bibliotecas primitivas de Altera).

## 🛠️ Tecnologías y Herramientas
* **Desarrollo FPGA:** Herramientas de desarrollo y síntesis (Altera/Intel).
* **Simulación:** ModelSim (entornos de simulación configurados en las carpetas `simulation/modelsim/`).
* **Lenguajes:** VHDL / Verilog.

## 📂 Prácticas del Curso

1. **Práctica 1:** Introducción a las herramientas de desarrollo de los FPGAs.
2. **Práctica 2:** Diseño de máquinas de estado.
3. **Práctica 3:** Construcción de Máquinas de estados usando memorias (Direccionamiento por Trayectoria).
4. **Práctica 4:** Construcción de Máquinas de estados usando memorias (Direccionamiento Entrada - Estado).
5. **Práctica 5:** Construcción de Máquinas de estados usando memorias (Direccionamiento Implícito).
6. **Práctica 6:** Secuenciador básico.
